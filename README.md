## IaC 웹 게시판 서비스

#### 프로젝트 간단 소개   
* 교내 IT 동아리 i-Keeper에서 Kubernetes 스터디를 진행하면서, 콘솔로 GCP GKE를 배포하였습니다. 수동으로 인프라를 관리하는 과정에서 관리의 불편함을 느껴 Terraform으로 GCP GKE 환경에서 AWS EKS 환경으로 마이그레이션하였습니다. 
* Kubernetes를 기반으로 Web-WAS-DB로 구성된 3-Tier 웹 애플리케이션 환경으로 구성하였고, 인프라 배포의 효율성과 편리성을 높이기 위해 Terraform을 사용하여 인프라를 코드화하였습니다.
